# TechPrep — Project Context

## Vision

A technical interview preparation app based on **spaced repetition (SM-2 algorithm)**.
The user chats with a coach agent to build their study plan, then receives questions
via a messaging interface (web first, Telegram/WhatsApp later) and gets AI feedback on their answers.

**Target user**: software engineer preparing for technical interviews.

## Database Schema

```sql
-- Study themes
CREATE TABLE themes (
    id          INTEGER PRIMARY KEY,
    name        TEXT NOT NULL,
    parent_id   INTEGER REFERENCES themes(id),  -- sub-themes
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- AI-generated questions
CREATE TABLE questions (
    id          INTEGER PRIMARY KEY,
    theme_id    INTEGER NOT NULL REFERENCES themes(id),
    content     TEXT NOT NULL,
    difficulty  INTEGER CHECK (difficulty BETWEEN 1 AND 5),
    type        TEXT CHECK (type IN ('concept', 'algo', 'system_design', 'behavioral')),
    created_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- SM-2 state per question (updated after each answer)
CREATE TABLE question_progress (
    id               INTEGER PRIMARY KEY,
    question_id      INTEGER NOT NULL UNIQUE REFERENCES questions(id),
    status           TEXT DEFAULT 'new',       -- 'new' | 'learning' | 'acquired'
    ef               REAL DEFAULT 2.5,         -- easiness factor
    interval_days    INTEGER DEFAULT 1,
    repetitions      INTEGER DEFAULT 0,
    next_review_at   DATETIME,
    last_reviewed_at DATETIME
);

-- Practice or mock interview sessions
CREATE TABLE sessions (
    id          INTEGER PRIMARY KEY,
    type        TEXT CHECK (type IN ('practice', 'mock')),
    started_at  DATETIME DEFAULT CURRENT_TIMESTAMP,
    ended_at    DATETIME,
    notes       TEXT
);

-- User answers
CREATE TABLE answers (
    id           INTEGER PRIMARY KEY,
    session_id   INTEGER NOT NULL REFERENCES sessions(id),
    question_id  INTEGER NOT NULL REFERENCES questions(id),
    content      TEXT,           -- transcribed or typed answer
    audio_path   TEXT,           -- path to voice file if applicable
    ai_feedback  TEXT,           -- feedback generated by Claude
    sm2_grade    INTEGER CHECK (sm2_grade BETWEEN 0 AND 5),
    answered_at  DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- User settings (key/value)
CREATE TABLE settings (
    key     TEXT PRIMARY KEY,
    value   TEXT NOT NULL
    -- example keys:
    -- 'daily_goal'         = '10'       (questions per day)
    -- 'teacher_severity'   = '3'        (1=lenient, 5=strict)
    -- 'preferred_channel'  = 'telegram'
    -- 'session_length'     = '20'       (minutes)
);
```

## Coach Agent — Planning Interface

### Role
The agent helps the user build their study plan through natural conversation.
It has access to tools for reading and modifying the database.

### System Prompt

```
You are a technical interview preparation coach.
You help the user build and manage their study plan.

You have access to a question database via your tools.
When the user asks you to generate questions on a topic,
use add_questions and provide a preview of what was created.

User context: software engineer preparing for technical interviews.
Themes in database: {themes}
Current settings: {settings}

Be proactive:
- If the user mentions a theme that doesn't exist yet, offer to create it.
- If the number of questions on a theme seems insufficient, flag it.
- After each action, give a clear summary of what was done.
```

### Question Generation Prompt (called inside add_questions)

```
You are an expert in technical interviews for software engineers.
Generate exactly {count} questions of type "{type}" on the topic "{theme_name}",
with a difficulty of {difficulty}/5.

Respond ONLY with a valid JSON array, no markdown, no comments.
Expected format:
[
  {
    "content": "question text",
    "difficulty": {difficulty},
    "type": "{type}"
  }
]

Rules:
- Questions must be precise and typical of a real technical interview.
- Difficulty 1 = beginner, 5 = senior expert.
- For algo questions, include a complexity constraint where relevant.
- Do not number the questions inside the content field.
```

## Interviewer Agent — Q&A Interface

### Role
Asks questions one by one, receives answers (text or transcribed voice),
evaluates using SM-2 grading, and gives pedagogical feedback.

### System Prompt

```
You are a technical interviewer for a software engineer position.
You ask questions one at a time and evaluate the answers.

Feedback severity: {teacher_severity}/5
  - 1 = very encouraging, highlight what's good
  - 5 = demanding, flag all inaccuracies and gaps

For each answer, you must:
1. Give structured feedback (strengths, areas to improve, missing elements)
2. Assign an SM-2 grade between 0 and 5:
   - 0: complete blackout, no answer
   - 1: incorrect answer, but topic seemed familiar
   - 2: incorrect answer, but easy to recall after seeing the solution
   - 3: correct answer with significant difficulty
   - 4: correct answer after slight hesitation
   - 5: perfect answer, immediate and precise

Always respond with this JSON format:
{
  "feedback": "feedback text",
  "grade": <integer 0-5>,
  "correct_answer_hint": "summary of expected answer if grade <= 2"
}
```

## SM-2 Algorithm

```python
def update_sm2(progress, grade):
    """
    progress : question_progress object
    grade    : integer 0-5 returned by the interviewer agent
    """
    if grade >= 3:
        if progress.repetitions == 0:
            progress.interval_days = 1
        elif progress.repetitions == 1:
            progress.interval_days = 6
        else:
            progress.interval_days = round(progress.interval_days * progress.ef)
        progress.repetitions += 1
    else:
        # Incorrect answer: reset
        progress.repetitions = 0
        progress.interval_days = 1

    # Update easiness factor
    progress.ef = max(1.3, progress.ef + 0.1 - (5 - grade) * (0.08 + (5 - grade) * 0.02))

    # Update status
    if progress.repetitions == 0:
        progress.status = 'new'
    elif progress.repetitions <= 2:
        progress.status = 'learning'
    else:
        progress.status = 'acquired'

    progress.next_review_at = datetime.now() + timedelta(days=progress.interval_days)
    return progress
```
